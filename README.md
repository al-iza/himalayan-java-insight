# Himalayan Insight

Create a simple, modern, visually appealing Sales & Outlet Analytics Dashboard for Himalayan Java.

This is ONLY a front-end demonstration/prototype for management. Do not build a complex backend, data pipeline, data engineering interface, AI system, or developer tools.

The goal is to demonstrate how management could view sales performance and outlet performance in one simple system.

Use realistic dummy data for demonstration purposes only.

BRAND / VISUAL STYLE

Create a premium café-business aesthetic inspired by Himalayan Java.

Use primarily:

White background

Black text

Warm yellow/gold as the main accent

Professional but visually attractive
